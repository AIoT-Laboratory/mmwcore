# mmwcore 0.8.0 candidate

This version is prepared for validation and has not been published. The latest published
Python version remains 0.7.1. Install the candidate from source with CPython 3.12 and Rust 1.97.

## Changes from 0.7.1

- Standardized byte-exact ADC compression/decompression with explicit file and frame-group APIs.
- Complete built-in Rust TI GTRACK 3DA and an independent Rust multiscale body tracker.
- Rust modules organized into I/O, DSP, and tracking; existing numerical imports remain available.
- Physical FFT scale and provenance checks, strict tracking oracle comparisons, and independently
  installed wheel/source-distribution validation on Linux and Windows.

## Migration

Use `compress_adc_file`, `decompress_adc_file`, `open_compressed_adc`, and `CompressedADCReader`
from `mmwcore.io`. `CompressedADC.decompress_frames` and `decompress_windows` restore raw bytes.
Historical archive API names remain aliases; existing `.mmwa` v3 data needs no conversion.
See the [compression API](../adc-compression.md).

The old `GTrack2D`, six-state `GTrack3D`, `PointTracker2D`, and `ClusterTracker2D` APIs are removed.
Choose `TiGTrack3D` or `ScatterBodyTracker` explicitly. These have different input, output, and
state contracts; they are not drop-in replacements. See [TI tracking](../ti-gtrack.md) and
[comparison contracts](../architecture.md#ti--multiscale-tracking-comparison).

For multiscale tracking, use `max_bodies` for a person-count prior and `max_components` for a
scatter-history resource limit. Use `CompressedADCReader.from_take` for verified capture packages
so the recorded configuration can resolve historical IQ labels without changing stored bytes.

## Support and licensing

The candidate supports CPython 3.12. Linux and Windows are covered by CI; macOS is not currently
validated. Source builds require Rust 1.97 and platform linker tools. Runtime requires no TI SDK
or external GTRACK library.

Python distributions contain Apache-2.0 code and a TI-device-only GTRACK component, declared as
`Apache-2.0 AND LicenseRef-TI-GTRACK`. The standalone `mmwcore` Rust crate remains Apache-2.0.
See [NOTICE](../../NOTICE) and [TI-LICENSE.txt](../../crates/mmwcore-ti-gtrack/TI-LICENSE.txt).

## Publication conditions

Run the full CI gate on the exact release commit, verify candidate wheels from a clean
installation, and build portable Linux wheels before PyPI publication. The CI Linux wheel is
a validation artifact, not necessarily a portable registry wheel. See the
[release process](../releasing.md). No existing version or tag is replaced.
